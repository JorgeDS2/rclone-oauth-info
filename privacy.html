Privacy Policy

Last updated September 29, 2026.

This personal, single-user Google Drive integration is operated by Jorge Davis using rclone and software he controls. The public website you are reading is informational. It has no login, analytics, advertising, or form that collects Google Drive content.

Access and use

With Jorge's Google authorization, the application can access Google Drive files and metadata. Full Drive permission allows reading, creating, modifying, and deleting files. Access is used to carry out Jorge's own file-management and assistant requests. If Jorge asks an AI assistant to analyze file content, that requested content may be processed by the assistant's configured model provider. The application does not sell Drive data or use it for advertising.

Storage and security

OAuth client details and authorization tokens are stored on Jorge's computer in local configuration files protected by operating-system file permissions. This informational website does not store those credentials or Drive files. Google processes OAuth authorization and Drive API requests. GitHub Pages hosts this website and may process normal website traffic under its own policies.

Control and deletion

Jorge can revoke the app's Google Drive access in his Google Account's third-party access settings. He can also remove locally stored rclone configuration and any local file copies. Revoking access does not by itself erase local copies already downloaded.

Contact

Questions about this policy can be posted to the repository's issues page. Do not post private files, tokens, or account details there.
